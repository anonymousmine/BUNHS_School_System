# 🚀 Railway MySQL Integration Setup Guide

## 📋 Overview

This guide sets up **Railway-integrated MySQL** for the BUNHS School System, completely eliminating local database dependencies.

## 🔧 Step 1: Create Railway MySQL Service

### Option A: Using Railway Dashboard (Recommended)

1. **Go to Railway Dashboard**: https://railway.app
2. **Click "New Project"** → "Add a Service"
3. **Select "MySQL"** from the database options
4. **Configure MySQL**:
   - **Database Name**: `bunhs_db_important`
   - **Username**: `bunhs_user`
   - **Password**: Auto-generated by Railway
5. **Click "Add MySQL"**

### Option B: Using railway-mysql.yml

1. **Add MySQL service to your project**:
   ```bash
   railway add mysql
   ```

2. **Use the configuration** from `railway-mysql.yml`

## 🔧 Step 2: Get MySQL Connection Details

1. **Click on your MySQL service** in Railway
2. **Go to "Connect" tab**
3. **Copy the connection details**:
   - **Host**: `containers-us-west-XXX.railway.app`
   - **Port**: `3306`
   - **Database**: `bunhs_db_important`
   - **Username**: `bunhs_user`
   - **Password**: (Generated by Railway)

## 🔧 Step 3: Set Environment Variables

In your Railway project (PHP app service), go to **Variables** tab and add:

```bash
# Railway MySQL Connection
RAILWAY_MYSQL_HOST=your-mysql-host.railway.app
RAILWAY_MYSQL_PORT=3306
RAILWAY_MYSQL_USER=bunhs_user
RAILWAY_MYSQL_PASSWORD=your-generated-password
RAILWAY_MYSQL_DATABASE=bunhs_db_important

# Alternative variables (fallback)
DB_HOST=your-mysql-host.railway.app
DB_PORT=3306
DB_USER=bunhs_user
DB_PASSWORD=your-generated-password
DB_NAME=bunhs_db_important

# Application settings
APP_DEBUG=true
RAILWAY_ENVIRONMENT=production
```

## 🔧 Step 4: Import Database Schema

### Method A: Using Railway MySQL CLI

1. **Connect to MySQL service**:
   ```bash
   railway mysql
   ```

2. **Import your database schema**:
   ```bash
   mysql -h your-mysql-host.railway.app -u bunhs_user -p bunhs_db_important < database_setup.sql
   ```

### Method B: Using Railway Dashboard

1. **Go to MySQL service** → "Connect" tab
2. **Use the connection string** with a MySQL client
3. **Import the schema** from `database_setup.sql`

## 🔧 Step 5: Deploy the Application

### Using the Deployment Script

```bash
# Make script executable
chmod +x deploy_railway.sh

# Run deployment
./deploy_railway.sh
```

### Manual Deployment

```bash
git add .
git commit -m "Integrate Railway MySQL service"
git push railway main
```

## 🐛 Troubleshooting

### Database Connection Failed
1. **Check MySQL service is running** in Railway dashboard
2. **Verify environment variables** are correctly set
3. **Test connection** using `test_railway.php`
4. **Check logs** in Railway dashboard

### Schema Not Found
1. **Import database schema** using MySQL CLI
2. **Verify database name** matches environment variables
3. **Check table structure** in Railway MySQL dashboard

### Headers Already Sent Error
✅ **Fixed**: No echo statements in configuration files
